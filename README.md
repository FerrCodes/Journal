## ✨ Fitur Utama

### 📝 Pencatatan Jurnal yang Kaya
- **Mood Tracker:** Pantau suasana hati harianmu dengan 5 skala emoji (😢 Sangat Sedih hingga 🤯 Luar Biasa).
- **Detail Kontekstual:** Tambahkan lagu yang sedang didengarkan (`song_title`, `song_artist`), cuaca hari itu, dan tag khusus.
- **Arsip & Favorit:** Kelola jurnalmu dengan fitur arsip agar dashboard tetap rapi, serta tandai momen terbaik sebagai favorit.

### 📊 Dashboard & Statistik
- Visualisasi aktivitas jurnal harian.
- Kalender interaktif untuk melihat riwayat tulisan berdasarkan tanggal.
- Log aktivitas pengguna (login/logout) untuk keamanan akun.

### 🛡️ Privasi & Manajemen Data
- **Export to PDF:** Unduh satu jurnal atau seluruh riwayat hidupmu dalam format PDF yang elegan dan siap cetak.
- **Pengingat Harian:** Notifikasi browser yang bisa disesuaikan waktunya agar tidak pernah lupa menulis.
- **Mode Gelap/Terang:** Transisi tema yang mulus untuk kenyamanan mata di segala kondisi cahaya.

### 📱 UI/UX Modern & Responsif
- **Collapsible Sidebar:** Navigasi desktop yang bisa diciutkan dengan *floating dropdown* yang elegan.
- **Mobile-First Design:** Bottom navigation khusus mobile dengan tombol "Jurnal Baru" yang menonjol (*floating action button style*).
- **Glassmorphism & Animasi:** Transisi halus menggunakan Tailwind CSS custom animations.

## 🛠️ Tech Stack

Project ini dibangun dengan teknologi modern yang berfokus pada performa dan *type-safety*:

| Kategori | Teknologi |
| :--- | :--- |
| **Frontend** | React 18, TypeScript (Strict Mode), Vite |
| **Styling** | Tailwind CSS, Lucide React (Icons) |
| **Backend & DB** | Supabase (PostgreSQL, Auth, Realtime) |
| **Utilities** | jsPDF (Export PDF), Sonner (Toast Notifications) |
| **Routing** | React Router DOM v6 |
